# 社区版功能底座与 WeLite 界面迁移

> 以下记录第一次迁移。后续已按用户要求改为直接复用原版渲染器；当前布局、交互和像素验证以 [原版 UI 精确迁移](welite-ui-parity.md) 为准。

## 评估结论

以 `weread-based-welite` 为开发与发行仓库，保留社区版功能实现，在其公开入口和数据模型上接入 WeLite 原生 UI。原 `welite` 仓库不改动。评估基线为社区版提交 `ae3930fa91e59ac72152fa709029e39fe6bcd1d6`（1.6.0）；本次没有替换协议、EPUB、位置映射、下载恢复、账号存储或批注数据层。

社区版覆盖公众号、书籍详情、书评、划线想法及其外部投影、多选下载、章节预下载、时长上报、SimpleUI / ZenUI 集成，功能面明显更完整。WeLite 已有的顶栏、统计布局、筛选草稿和设备下拉控件适合迁入；直接复制整个原插件会产生两套账号、缓存和同步状态，因此只迁移原生显示与设备控制模块。

## 已实施的交互

- WeLite 顶栏：品牌菜单、缓存网络状态、显式书架刷新、固定宽度时钟、电量图形。分钟更新只重绘顶栏，不重建封面。
- 本月 / 本周 / 今日阅读收听统计；未知值显示「—」。品牌菜单的「刷新阅读统计」启动独立后台任务，每次最多两次请求、35 秒任务期限，无自动重试。今日复用 UTC+8 日桶，跨日旧值不会冒充今日数据。当前统计为会话缓存，重启后需要显式刷新。
- 书架 / 本地、搜索和筛选排序。统一筛选面板只有「应用」才写入偏好并重置页码；取消不改变状态。沿用社区版五种排序和下载判定，不把最近阅读伪装成最近加入。
- 本地分类合并已知下载记录与云端书架，包含章节文件和从云端移除的书；文件有效性复用社区版缓存校验。分页复用已准备列表。
- 新安装默认封面分页，最多三列两行 / 六张封面；保留已有列表和连续滚动偏好，品牌菜单可切换。封面保留社区版私密阅读、读完标记，增加本地可读及已知百分比文字、书名与作者。
- 书架顶部下滑和 Menu 键打开 WeLite 下拉；阅读顶部向下滑动及原生菜单提供同一面板，含 WIFI、夜间模式、完整刷新、KO 设置、社区功能入口、原生背光档位/滑块、当前页与目录导航。原社区快捷菜单保留。
- 书籍点击仍打开社区版详情，以保留书评、下载、批注及阅读操作。**没有把未经确认的云端坐标接入原 WeLite 阅读桥。** 微信分组与公众号由「书架 ▾」进入；账号、时长上报、缓存、划线、全部设置由「welite → 微信读书 · 全部功能」进入。
- 在线更新源改为 `Xlawy/weread-based-welite`，避免原作者发布覆盖定制。fork 必须发布符合原更新器校验要求的安装包和校验文件后才能在线更新；未测试真实发布下载。

这些是基于社区数据语义的界面适配，并非旧项目所有实现的逐文件替换。下载标记使用「本地可读」，包含部分章节；显示原始缓存百分比，缺失显示「—」，刷新书架不会隐式逐书刷新阅读位置。社区版完成标记和私密标记继续保留。

## 模块边界和测试

`library.lua → library_view.lua → welite/home.lua` 连接社区书架控制器与 WeLite 显示。`welite/local_shelf.lua` 仅合并记录，文件校验由社区 cache 模块注入；`welite/filter.lua` 保留草稿状态；`welite/statistics.lua` 通过社区 BackgroundWorker 获取汇总，校验账号和认证快照后才接收结果，不写子进程账号文件。

`reader_lifecycle.lua / menu.lua → welite/reader_controls.lua → welite/pulldown.lua → welite/controls.lua` 连接宿主设备和原生阅读器；WIFI 扫描使用迁入的单任务 worker，最多 256 项、25 秒，关闭时取消。未接入第二套云端同步。`clock`、`battery`、`display`、`lightslider`、`controlicon` 是显示/交互模块，全部有对应真实宿主测试。

映射维护于 `tests/module-map.json`。未修改的上游模块保留原 spec 套件；没有声称它们全部具备一对一映射或满足本项目所有新增约束。新增测试脚本由 Python 单元测试验证映射拒绝路径和发行包内容。

```sh
make check
make test
make package
```

本机 `make test` 可发现相邻 `welite/.dev/koreader/koreader-emulator-*/koreader` 的唯一构建；其他机器使用 `KOREADER_RUNTIME=/绝对路径/koreader make test`。测试不会自动下载或编译。启动器临时链接插件并复制独立测试，拒绝覆盖已有测试目标，完成后清理；结果与截图位于 `.dev/reports/`。

- 上游 Lua spec 全量运行，并加入统计与本地列表回归。
- 真实 KOReader 断言覆盖插件发现、全部菜单构造、主页、筛选应用/取消、长时长、图标、设备能力缺失、背光、扫描取消/超时、worker、阅读面板和生命周期。
- 渲染尺寸：600×800、320×600、600×400、1072×1448。测试使用虚构书籍和无封面缓存；截图不代表真实账号内容。
- 可验证的操作上限：主页最多六张封面；首次构造/下拉/时钟更新不调用统计请求；显式统计任务两次请求；本地合并同一记录只校验一次。测试数据含 1,000 本书的社区分页回归。
- 新增 UI 无外部运行时依赖；使用 KOReader 原生字体/控件和六个小 SVG。开发文件、测试、截图、日志不进入发行包；保留 LICENSE、NOTICE 和原第三方字体许可证。

这些不是 Kindle CPU、峰值内存、Wi-Fi 或墨水屏耗时测量。真机还需验证触摸/按键、休眠恢复、背光、网络认证、残影和真实微信服务。

## 保留上游行为的限制

社区 `runOnlineTask` 仍通过 `scheduleIn` 在 UI 线程调用网络，并不是真正异步；书架刷新、详情、统计详情等原路径可能等待网络。此次仅新增统计汇总采用后台 worker，没有将原协议和全功能执行模型一并重写。上游全局扫描、同步冲突与未知写入结果也不能由 UI 测试证明完整正确。新增路径遵循轻量化约束，**不能据此宣称整个社区底座已完成 AGENTS.md 性能审计**。

阅读面板目录导航使用当前 EPUB 的宿主目录；跨独立章节下载继续通过社区详情/章节入口操作，不在下拉绘制时下载或扫描全书。返回首页使用宿主关闭/保存流程和 FileManager 插件实例，不自行写阅读位置。
