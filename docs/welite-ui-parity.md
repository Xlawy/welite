# 原版 WeLite UI 精确迁移

2026-10-21，按用户要求取代第一次混合布局。上次仅在社区书架上增加 WeLite 风格顶栏，页边距、统计对齐、分类栏、封面与分页仍有明显差异。本次直接迁入原仓库 `welite.koplugin/welite/shelf.lua`、`filter.lua` 的原生渲染实现，只转换模块命名空间，数据通过单独适配层接入社区功能。

## 一致范围

- 24 逻辑单位页边距；六槽顶栏（WeLite、登录、WIFI、同步状态、时钟、电量）；原字体、字号、固定时钟与电池图形。
- 左对齐本月 / 本周 / 今日统计，原分隔线和留白；书架 / 本地下划线，右侧独立圆角「同步」按钮；下一行摘要和「筛选 / 排序」。
- 原封面比例与白底占位、已下载 / 部分下载和百分比角标、单行省略书名、作者及原底部分页。页面大小沿用原版屏幕计算，封面 worker 与渲染页面共用测量结果。
- 原筛选草稿：云端顺序、最近阅读、最近加入、书名；全部 / 全书 / 部分 / 未下载；取消不应用，应用回到第一页。
- 原主页与阅读下拉布局、WIFI、背光、夜间模式、KO 设置、WeLite 设置；WeLite 设置复用原时区和启动选择界面。原顶部点击、下滑和拖动释放手势接入阅读器。
- 点击已下载书籍调用社区本地阅读入口，长按保留详情、下载、批注等社区功能。品牌菜单前四项恢复「下载书籍… / 重新加载本页封面 / 切换账号 / 退出登录」。额外社区能力集中在新增的「社区功能…」子菜单，不改变主页布局。

界面一致不等于伪造数据：登录与同步显示实际状态；全书 / 部分分类复用社区文件校验，未知进度显示「—」。最近加入仅使用实际返回的 `shelfTime` / `shelfUpdateTime`，字段缺失时保持云端顺序；不冒用本地修改时间。旧账号已保存的排序/列表偏好仍保留，新安装默认云端顺序及封面视图。

原社区账号、下载、同步、公众号、书评和划线页面继续保留其功能实现；它们不是原 WeLite 已有界面的像素复刻对象。统计汇总仍通过社区功能菜单显式后台刷新，未在绘制或翻页时加入请求。

## 模块与回归

`library.lua → library_view.lua → shelf_adapter.lua → shelf.lua`：控制器负责账号、下载、排序和缓存；adapter 只转换字段与回调；shelf 负责原版像素和手势。原社区 view 保留用于列表视图和选择器。`getLayout` 每种当前屏幕配置只测量一次空界面，不解码封面，不发网络请求；翻页继续复用社区准备列表和当前页封面加载。

原版参考实现冻结在 `spec/reference/`，哈希记录于 `source-hashes.json`；它独立于当前适配器，仅供测试且不进入发行包。真实 KOReader 中，用相同封面、书名、作者、统计和固定设备状态分别渲染原版与迁移版，逐字节比较整个灰度帧缓冲：

- 主页：600×800、320×600、600×400、1072×1448，均为 **0 像素差异**。
- 筛选面板、主页下拉、阅读下拉：600×800，均为 **0 像素差异**。

回归还验证点击/长按路由、分页、本地缓存、同步中禁用、同步失败文字、登录入口、筛选应用/取消、设置保存、启动决策和生命周期清理。模块映射见 `tests/module-map.json`。原版及迁移版预览在 `.dev/reports/original-*` 和 `exact-*`。

此处“一致”仅指上述相同数据、状态、字体与屏幕配置下的原生渲染验证，不包含真实云端数据一致性或 Kindle 物理显示验收。宿主版本与上游网络线程限制仍见 `welite-migration.md`。

## 主页数据补全回归（2026-10-21）

书架接口的本地缓存记录不含 `progress`；此前适配器直接读这个字段，导致百分比长期未知。主页统计此前只有手动刷新入口。现在 `library.showShelfView` 在画出缓存后调用 `statistics.ensure` 和 `progress.ensure`，由社区 BackgroundWorker 在子进程请求数据，完成后重绘当前视图。

- 统计每次最多 2 个请求，35 秒任务超时；一小时内自动尝试一次，无轮询或自动失败重试，手动刷新仍可用。
- 进度每批最多请求当前页 6 本书，60 秒任务超时，一个进度 worker；缓存最多 128 条（包括失败标记）。翻页只补当前页，书架同步清除进度缓存以允许重试。缺失或失败仍显示未知，不伪造 0%。
- 结果按账号和凭证指纹校验；账号切换取消旧任务。开发依赖与模拟器不进入发行包。
- 确定性测试记录：主页绘制回调内请求数 0，进度首批请求数 6，重复当前页额外请求数 0，统计任务请求数 2。真实桌面 KOReader 测试确认后台结果使主页时间与卡片 `42%` 实际显示。
- `make test`：78 组 Lua spec、68 项 KOReader 集成测试、7 项 Python 工具测试通过。上述请求规模来自注入传输的测试，不是真实微信接口耗时或 Kindle 真机性能测量。
