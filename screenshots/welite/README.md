# WeLite 界面截图

这些截图供项目 README 展示，拍摄于 2026-10-22，基于 WeLite v1.0.1。

- 使用项目现有 KOReader SDL 模拟器、真实 Lua UI 控件和阅读排版引擎，以 600 × 800 分辨率直接导出屏幕。
- 书架、书籍详情、设置、搜书、阅读控制栏与想法弹窗均来自当前产品实现，未对截图进行拼接或绘制 UI。
- 书籍、作者、封面、出版社、正文、评论与阅读统计均为自建演示数据；阅读正文来自本地演示 EPUB，不连接真实微信账号。设备状态和控制栏使用演示能力数据。
- 演示封面使用 KOReader 字体与简单图形生成，不使用真实图书封面或私人书架。
- 弹窗后的灰色背景由产品原生绘制。截图仅说明界面，不能代替网络、同步或 Kindle 性能测试。
